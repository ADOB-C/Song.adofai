# 压缩基准与默认档

`adofai-music -i CHART -bench [-slice MB] [-full] [-threads N]`：读入谱面（明文/.xz/.zst 均可），在内存里对
各档位压缩→解压→比字节，并按谱面自身的「文本字节/音频秒」外推 3 分钟体积、与
100 MB 预算比对。**全程零落盘**；默认取文本中段 256 MiB（= 4 个 64 MiB block，
MT 才真正跑起来）。

真实谱面（1.24 GB 文本，190.7 s，48 kHz；`bench` 默认参数）：

```
codec lvl        size    ratio  comp MB/s   dec MB/s  est 3min  budget roundtrip
xz    3       13.53 MB    19.8x       82.7     1685.0    58.9 MB    PASS OK
xz    6       12.27 MB    21.9x       42.9     1657.7    53.5 MB    PASS OK
xz    9e      10.07 MB    26.6x       11.2     1388.5    43.9 MB    PASS OK
zstd  3       16.56 MB    16.2x     5699.9     3078.4    72.1 MB    PASS OK
zstd  12      15.15 MB    17.7x      593.8     3192.7    66.0 MB    PASS OK
zstd  19      12.22 MB    22.0x       20.1     3764.6    53.2 MB    PASS OK
```

## 默认值推导（换算 4 分钟 ≈1.56 GB 文本，预算 100 MB）

| 档位 | 4 分钟体积 | 预算余量 | 编码耗时 | 定位 |
|---|---|---|---|---|
| xz 3 | ~78 MB | 21% | ~19 s | 快，余量一般 |
| **xz 6（默认）** | **~71 MB** | **29%** | **~36 s** | 拐点：体积/耗时平衡 |
| xz 9e | ~59 MB | 41% | ~140 s | 归档档，最小体积 |
| zstd 3 | ~96 MB | 4% | ~0.3 s | 极快，但几乎贴线 |
| zstd 12 | ~88 MB | 12% | ~3 s | zstd 快速档上限 |
| **zstd 19（默认）** | **~71 MB** | **29%** | **~78 s** | 体积≈xz 6，解码快 ~2x |

- `xz 6` / `zstd 19` 是唯二「≈71 MB 且余量 29%」的点，故为默认。
- 最小体积用 `-xz-level 9e`（+18% 节省、约 4x 时间）；秒级编码用
  `-zstd-level 3`（余量仅 4%，勿用于更长曲目）。
- `zstd 22` 不列入矩阵：同片实测只比 19 小 1.3%（3.10 vs 3.14 MB），慢 2.3x。
- 校验：该谱面磁盘上实际 45.2 MB/190.7 s，换算 3 分钟 ≈42.7 MB，与 xz 9e 外推的
  43.9 MB 吻合。

产物是标准 `.xz`（CRC64）/ `.zst`（带校验和），与 `xz` / `zstd` 命令行互通。
读压缩谱面需整流解压进内存（超大谱面留意内存）。
